# PHD Energia Solar — landing page

Landing page de captação de leads para a **PHD Energia Solar**, empresa de projeto, homologação, instalação e monitoramento de sistemas fotovoltaicos. Projeto feito para cliente da Agência Wave.

**Site no ar:** https://phd-energia-solar.vercel.app

![PHD Energia Solar](imagens/hero.jpg)

## Seções

- Hero com formulário de proposta
- Simulação a partir da conta de luz
- Como funciona e tipos de projeto atendidos
- Resultados reais de clientes (instalações na Bahia)
- Equipe, sobre a empresa e perguntas frequentes
- Botão flutuante de WhatsApp

## Stack

HTML, CSS e JavaScript puros, sem build. Animações de entrada com `IntersectionObserver`. Deploy na Vercel.

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
npx serve .
```
